# Mind Emotions — Área da Família

Portal demonstrativo, responsivo e mobile-first para uma família acompanhar indicadores escolares e check-ins emocionais fictícios. A experiência mantém três perfis, dashboard familiar, perfis individuais, gráficos, diário/check-in de três perguntas, temas e conversas demonstrativas.

> **Demonstração, não serviço clínico ou escolar.** Os dados são exemplos locais mantidos em memória no navegador. Não há backend, autenticação, armazenamento persistente nem envio real de mensagens a professores. Os indicadores não constituem avaliação psicológica, diagnóstico ou aconselhamento. Não inserir informações pessoais reais.

## Executar localmente

Requer Node.js 20 ou superior e npm.

```bash
npm ci
npm run dev
```

O Vite informa o endereço local. Para validar uma versão de produção:

```bash
npm test
npm run build
npm run preview
```

## Estrutura

```text
src/
  components/  componentes visuais compartilhados
  data/        perfis e listas demonstrativas
  domain/      cálculos e regras do check-in, sem dependência de UI
  styles/      folhas CSS agrupadas pelo entry point index.css
  main.jsx     composição da aplicação React
 tests/        testes nativos do Node para regras de domínio
```

## Qualidade e contribuição

- `npm test`: testes automatizados de dados, métricas e check-in.
- `npm run format`: formata código e arquivos de configuração com Prettier.
- `npm run format:check`: verifica formatação.
- `npm run build`: compila a aplicação para produção.

Antes de propor alterações, rode os testes e o build. Preserve o caráter demonstrativo, os limites de privacidade acima e a acessibilidade/responsividade da interface. Consulte [CONTRIBUTING.md](CONTRIBUTING.md).

## Publicação

O workflow de GitHub Actions em `.github/workflows/pages.yml` publica no GitHub Pages quando executado conforme a configuração do repositório. A última URL conhecida é [tgmidasx7.github.io/MIND-EMOTIONS-ULTRA](https://tgmidasx7.github.io/MIND-EMOTIONS-ULTRA/); a disponibilidade e o deploy após esta refatoração ainda precisam ser confirmados no GitHub Actions.

# Contribuindo

Obrigado por ajudar a melhorar o Mind Emotions — Área da Família.

## Fluxo recomendado

1. Mantenha mudanças pequenas e focadas; preserve os recursos e a identidade visual existentes.
2. Separe regras e cálculos sem interface em `src/domain/`, conteúdo em `src/data/` e componentes compartilhados em `src/components/`.
3. Para alterações em regras de domínio, inclua ou atualize testes em `tests/`.
4. Execute `npm test`, `npm run format:check` e `npm run build` antes de concluir.
5. Descreva o propósito, impactos visuais e validações realizadas na proposta.

## Privacidade e escopo

Este projeto é uma demonstração front-end. Não adicione dados reais de estudantes, integração escolar, coleta de informações sensíveis ou alegações clínicas sem uma revisão explícita de segurança, privacidade e escopo. Nunca descreva dados fictícios ou mensagens demonstrativas como reais.

      - name: Add GitHub Pages route fallback

          path: dist

      </div>

      <div className="metric-value">
        {value}
        <em>{suffix}</em>
      </div>
      <div className="metric-hint">{hint}</div>
    </div>
  );
}
export function EmotionRow({ name, value, positive }) {
  return (
    <div className="emotion-row">
      <span>{name}</span>
      <div className="track">
        <div
          style={{
            width: `${value}%`,
            background: positive ? "#63b99a" : "#ee929e",
          }}
        />
      </div>
      <b>{value}%</b>
    </div>
  );
}

export function Subnav({ active, onSelect, items }) {
  return (
    <nav className="pro-subnav" role="tablist">
      {items.map(([id, label]) => (
        <button
          type="button"
          key={id}
          role="tab"
          aria-selected={active === id}
          className={active === id ? "active" : ""}
          onClick={() => onSelect(id)}
        >
          {label}
        </button>
      ))}
    </nav>
  );
}

const clamp = (value, min = 0, max = 100) =>
  Math.max(min, Math.min(max, Math.round(value)));

/** Apply a completed self-report check-in without mutating the original student. */
export function applyCheckin(
  student,
  answers,
  { note = "", timestamp = new Date() } = {},
) {
  const ids = quizQuestions.map((question) => question.id);
  if (
    !student ||
    ids.some(
      (id) =>
        !Number.isInteger(answers?.[id]) || answers[id] < 0 || answers[id] > 3,
    )
  ) {
    throw new Error(
      "Complete as três perguntas antes de registrar o check-in.",
    );
  }
  const next = {
    ...student,
    pos: student.pos.map((value) => clamp(value, 10, 98)),
    neg: student.neg.map((value) => clamp(value, 8, 90)),
    history: [...student.history],
    checkins: [...student.checkins],
  };
  const mood = answers.mood,
    energy = answers.energy;
  const moodDelta = [4, 2, 0, -3][mood];
  next.pos[4] = clamp(next.pos[4] + moodDelta, 10, 98);
  next.pos[2] = clamp(next.pos[2] + (mood < 2 ? 1 : -1), 10, 98);
  next.neg[4] = clamp(
    next.neg[4] + (mood === 3 ? 3 : mood === 2 ? 1 : -2),
    8,
    90,
  );
  next.pos[3] = clamp(next.pos[3] + [3, 2, -2, -3][energy], 10, 98);
  next.focus = clamp(next.focus + [2, 1, -2, -3][energy], 20, 98);
  next.history.push(
    clamp(
      next.history.at(-1) +
        Math.round((moodDelta + [3, 2, -2, -3][energy]) / 2),
      20,
      98,
    ),
  );
  if (next.history.length > 8) next.history.shift();
  next.rewards += 25;
  next.checkins.unshift({
    date:
      timestamp instanceof Date
        ? timestamp.toLocaleString("pt-BR", {
            day: "2-digit",
            month: "short",
            hour: "2-digit",
            minute: "2-digit",
          })
        : String(timestamp),
    mood: quizQuestions[0].options[mood][1],
    energy: quizQuestions[1].options[energy][1],
    support: quizQuestions[2].options[answers.support][1],
    note: note.trim() || "Sem observação adicional.",
  });
  return next;
}

const clamp = (value, min, max) => Math.max(min, Math.min(max, value));

/** Arithmetic mean of the student's current illustrative subject grades. */
export function average(student) {
  const grades = student?.grades ?? [];
  if (grades.length === 0) return 0;
  return grades.reduce((sum, [, grade]) => sum + grade, 0) / grades.length;
}

/** Positive share of the configured emotional indicators (demo index, not diagnosis). */
export function wellbeing(student) {
  const positive = student?.pos ?? [];
  const negative = student?.neg ?? [];
  const positiveTotal = positive.reduce((sum, value) => sum + value, 0);
  const total = positiveTotal + negative.reduce((sum, value) => sum + value, 0);
  return total > 0 ? Math.round((positiveTotal / total) * 100) : 0;
}

/** Demo focus indicator; derive from motivation and creativity only if absent. */
export function focusScore(student) {
  if (Number.isFinite(student?.focus))
    return clamp(Math.round(student.focus), 0, 100);
  const values = student?.pos ?? [];
  return values.length > 3 ? Math.round((values[0] + values[3]) / 2) : 0;
}

/** Shared weighted engagement score used by cards, comparison and profile. */
export function engagement(student) {
  const academic = average(student) * 10;
  const attendance = Number.isFinite(student?.attendance)
    ? student.attendance
    : 0;
  return Math.round(
    academic * 0.4 +
      wellbeing(student) * 0.25 +
      attendance * 0.2 +
      focusScore(student) * 0.15,
  );
}

export function familySummary(students) {
  if (!students?.length) return { engagement: 0, wellbeing: 0, attendance: 0 };
  const mean = (values) =>
    Math.round(values.reduce((sum, value) => sum + value, 0) / values.length);
  return {
    engagement: mean(students.map(engagement)),
    wellbeing: mean(students.map(wellbeing)),
    attendance: mean(students.map((student) => student.attendance ?? 0)),
  };
}

const pathTabs = Object.fromEntries(
  Object.entries(tabPaths).map(([tab, path]) => [path, tab]),
);
const studentSlugs = { 1: "isabela", 2: "gabriel", 3: "manuela" };
const slugStudents = Object.fromEntries(
  Object.entries(studentSlugs).map(([id, slug]) => [slug, Number(id)]),
);

function cleanBase(base) {
  const segments = String(base || "/")
    .split("/")
    .filter(Boolean);
  return segments.length ? `/${segments.join("/")}/` : "/";
}

export function appUrl(tab, studentId = 1, base = "/") {
  const route = tabPaths[tab] || tabPaths.home;
  const prefix = cleanBase(base);
  const url = `${prefix}${route}`;
  const slug = studentSlugs[studentId];
  return slug && studentId !== 1 ? `${url}?filho=${slug}` : url;
}

export function parseAppUrl(pathname, search = "", base = "/") {
  const prefix = cleanBase(base);
  let relative = String(pathname || "/");
  if (relative.startsWith(prefix)) relative = relative.slice(prefix.length);
  else relative = relative.replace(/^\/+/, "");
  relative = relative.replace(/\/+$/, "");
  const tab = pathTabs[relative] || "home";
  const params = new URLSearchParams(search);
  const studentId = slugStudents[params.get("filho")?.toLowerCase()] || 1;
  return { tab, studentId };
}

                                aria-pressed={quizAnswers[q.id] === choice}
                                onClick={() => {
                                  setQuizAnswers((v) => ({
                                    ...v,
                                    [q.id]: choice,
                                  }));
                                  setQuizDone(false);
                                }}
                              >
                                <span className="quiz-emoji">{emoji}</span>
                                <small>{label}</small>
                              </button>
                            ))}
                          </div>
                        </fieldset>
                      ))}
                    </div>
                    <label className="quiz-note-label">
                      Observação rápida (opcional)
                      <input
                        value={quizNote}
                        onChange={(e) => setQuizNote(e.target.value)}

                    </label>
                    {quizDone ? (

                    ) : (

                      </button>
                    )}
                    <div className="quiz-disclaimer">
                      🔒 Respostas simuladas neste protótipo e mantidas apenas

                    </div>
                  </div>
                  <aside className="quiz-history panel">
                    <span className="history-mark">✧</span>
                    <h3>Registro recente</h3>
                    {student.checkins.length ? (

                      </p>

                    </div>
                  </aside>
                </div>
              )}

                          Humor: {c.mood} · Energia: {c.energy} · Apoio:{" "}

                        <span>8 SEM.</span>

                            className="bar-group"

                      <div className="grade-chart">
                        {student.grades.map(([name, value]) => (
                          <div key={name} title={`${name}: ${value}`}>

                        <div>
                          <h3>Radar emocional</h3>

                        {positive.map((name, i) => (
                          <div key={name}>

                            <i>

                      </div>

              )}
            </section>
          )}
        </div>
      </main>
      {compareOpen && (
        <div

          onMouseDown={(e) =>
            e.target === e.currentTarget && setCompareOpen(false)
          }
        >
          <section
            className="compare-modal"
            role="dialog"
            aria-modal="true"
            aria-labelledby="compare-title"
          >
            <div className="compare-head">
              <h2 id="compare-title">Comparativo familiar</h2>
              <button
                className="compare-close"
                onClick={() => setCompareOpen(false)}
              >
                Fechar ×
              </button>
            </div>
            <p className="compare-legend">
              Amostras fictícias para comparação visual · não representam
              avaliação escolar oficial.
            </p>
            <div className="compare-row">
              <span>Estudante</span>
              <b>Média</b>
              <b>Bem-estar</b>
              <b>Engaj.</b>
            </div>
            {students.map((s) => (
              <div className="compare-row" key={s.id}>
                <span>
                  {s.emoji} {s.name}
                </span>
                <b>{average(s).toFixed(1)}</b>
                <b>{well(s)}%</b>
                <b>{engagement(s)}%</b>
              </div>
            ))}
          </section>
        </div>
      )}
      <nav className="mobile-tabs">
        {tabs.map(([id, label, Icon]) => (
          <button
            key={id}
            className={tab === id ? "on" : ""}
            onClick={() => navigateTab(id)}
          >
            <Icon size={19} />
            <small>{label === "Quiz emocional" ? "Quiz" : label}</small>
          </button>
        ))}
      </nav>
    </div>
  );
}

import test from "node:test";
import assert from "node:assert/strict";
import { seedStudents } from "../src/data/students.js";
import { positiveEmotions, negativeEmotions } from "../src/data/emotions.js";
import {
  average,
  wellbeing,
  focusScore,
  engagement,
  familySummary,
} from "../src/domain/metrics.js";
import { applyCheckin, quizQuestions } from "../src/domain/checkin.js";

const [isabela, gabriel, manuela] = seedStudents;

test("demo profiles have complete, bounded sample data", () => {
  assert.equal(seedStudents.length, 3);
  assert.equal(positiveEmotions.length, 5);
  assert.equal(negativeEmotions.length, 5);
  for (const student of seedStudents) {
    assert.equal(student.grades.length, 8);
    assert.ok(student.grades.every(([, grade]) => grade >= 0 && grade <= 10));
    assert.equal(student.pos.length, 5);
    assert.equal(student.neg.length, 5);
  }
});

test("metrics use consistent source values and handle missing data safely", () => {
  assert.ok(Math.abs(average(isabela) - 8.575) < 1e-10);
  assert.equal(wellbeing(isabela), 74);
  assert.equal(focusScore(gabriel), 84);
  assert.equal(
    engagement(gabriel),
    Math.round(
      average(gabriel) * 10 * 0.4 +
        wellbeing(gabriel) * 0.25 +
        98 * 0.2 +
        84 * 0.15,
    ),
  );
  assert.deepEqual(familySummary([]), {
    engagement: 0,
    wellbeing: 0,
    attendance: 0,
  });
  assert.equal(familySummary(seedStudents).attendance, 97);
});

test("check-in requires answers to all three questions", () => {
  assert.equal(quizQuestions.length, 3);
  assert.throws(
    () => applyCheckin(isabela, { mood: 0, energy: 0 }),
    /três perguntas/,
  );
});

test("check-in is immutable, records the self-report and updates related demo indicators", () => {
