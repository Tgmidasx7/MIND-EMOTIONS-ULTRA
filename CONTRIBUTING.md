# Contribuindo

Obrigado por ajudar a melhorar o Mind Emotions — Área da Família.

## Fluxo recomendado

1. Mantenha mudanças pequenas e focadas; preserve os recursos e a identidade visual existentes.
2. Separe regras e cálculos sem interface em `src/domain/`, conteúdo em `src/data/` e componentes compartilhados em `src/components/`.
3. Para alterações em regras de domínio, inclua ou atualize testes em `tests/`.
4. Execute `npm test`, `npm run format:check` e `npm run build` antes de concluir.
5. Descreva o propósito, impactos visuais e validações realizadas na proposta.

## Privacidade e escopo

Este projeto é uma demonstração front-end. Não adicione dados reais de estudantes, integração escolar, coleta de informações sensíveis ou alegações clínicas sem uma revisão explícita de segurança, privacidade e escopo. Nunca descreva dados fictícios ou mensagens demonstrativas como reais.
